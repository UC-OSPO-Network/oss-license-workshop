This lesson helps learners understand open source software (OSS) licensing. It is for people who write or share code and are unsure which license to choose, and for anyone who is curious about how open source licenses work.

The [learner profiles](profiles.html) describe five people this lesson was written for.

## Learning Objectives

After completing this lesson, learners will be able to:

- Describe what an open source license is.
- Describe an example of what can happen if a license isn't applied to a project.
- Identify the difference between permissive and copyleft licenses, with an example of each.
- List the most common open source licenses.
- Describe an example of what can happen when a project's dependencies' licenses clash.
- Choose a license for an example project and explain why that's the right choice.

:::::::::::::::::::: prereq

- No licensing knowledge is needed. This lesson is the starting point.
- A basic understanding of what open source software is.
