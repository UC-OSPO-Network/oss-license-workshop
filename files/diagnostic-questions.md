# Diagnostic questions (draft for the group)

The Carpentries audience guidance asks for 1 or 2 questions to use before the lesson, to check whether someone fits the intended audience. These go on a registration form or a pre-workshop survey. They are not lesson text.

## Question 1

Have you written code that you want to share, or that someone has asked to use?

* Yes, I have code ready to share, or others asked for it.
* Not yet, but I use open source tools and want to understand their licenses.
* No, and I do not use open source tools.

Fits the lesson: the first two answers. Camila, Valentina, and Santiago give the first answer. Mateo gives the second. The third answer is outside the audience.

## Question 2

Which sentence describes you best?

* I know nothing about software licenses.
* I know licenses exist, but I do not know how the types differ.
* I can explain the difference between a permissive and a copyleft license.

Fits the lesson: the first two answers. The third answer suggests the lesson starts too low for this person.

Vocabulary and language: the lesson uses terms such as "license", "permissive", and "copyleft". If a registrant's first language is not English, ask the group whether the form needs plain-language versions of these words.
